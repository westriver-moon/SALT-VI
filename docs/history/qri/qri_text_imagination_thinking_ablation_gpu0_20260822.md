# QRI 文本级想象：thinking 开关消融

日期：2026-08-22
服务器：`lab929-3090`，物理 GPU0（RTX 3090）
模型：`Qwen3.8-27B-UD-Q4_K_XL` + `mmproj-F16`
实验 ID：`qri-text-imagination-thinking-ablation-gpu0-20260822`

## 结论

将 QRI 收缩到文本层面是可行的。当前 VLM 已能在不生成或改写图片的前提下完成：

1. 从放大的 LR/Swin ROI 对照中提取局部可见事实；
2. 显式调用对象、设计和文化世界知识；
3. 输出 3–5 个带概率、互斥且可回退的文本世界；
4. 将像素观察、世界知识推断和未决信息分开；
5. 在本地按归一化概率确定性采样语义世界，不再生成多张候选图。

全数据集生产默认应使用 `no_thinking`。高强度 thinking 的平均耗时是其 3.40 倍，
并没有稳定提升具体识别：它改善了模糊物体的不确定性校准和眼镜组成描述，但在卡通
背包上反而降低了“樱桃小丸子”识别的概率，并加入了较可疑的白色头饰解释。因此，
thinking 只适合由不确定性或任务价值触发的少量 ROI，不应逐样本默认开启。

- 权威指标：上述产物目录中的 `metrics.json`

实现复用了旧 QRI 的两项有效机制：`roi_comparison_board` 四格 ROI 放大重看，以及按
候选概率采样语义世界。它删除了旧 v2 中为满足覆盖率而自动插入通用正向候选的行为，
也没有调用 SD、PASD、diffusers 或任何图片写回代码。实验目录中的 ROI board 仅是输入
重排和放大产生的诊断/复查上下文，不是扩散模型生成结果。

## 细颗粒描述审计

### 1. 卡通抽绳背包：世界知识识别已可用

`no_thinking` 先描述出浅蓝色抽绳包、肩带、中央圆脸、深色头发和刘海轮廓，再把
“樱桃小丸子”列为 `mixed` 假设，概率 0.75；通用深发卡通人物为 0.15，未决图案为
0.10。它同时明确眼、嘴和小字不可辨认。

这已经达到当前所需的抽象层级：对象类别、颜色、携带方式、中心图案、人物发型和
候选文化角色均被描述，而且知识推断没有冒充像素事实。

`thinking=high` 增加到四条观察和两个知识项，却将具体角色假设降到 0.30，把“通用
90 年代动漫女孩”置为 0.50，并加入主要依赖非权威 Swin 提案的“白色头饰”。因此该例
中 thinking 更长，但更不精确。

### 2. 模糊眼区：可描述组成，不能把细节当事实

`no_thinking` 给出眼镜 0.55、无眼镜 0.30、未决 0.15。它能描述眼平线附近的弱横线和
矩形阴影，但只把“矩形眼镜”作为混合证据假设。

`thinking=high` 进一步枚举前框横线、成对镜片样暗区、鼻梁连接和靠耳镜腿，并将四项
全部标为弱证据；概率为眼镜 0.50、无眼镜 0.30、未决 0.20。这种输出对结构化文本融合
有用，但组成位于单像素/亚像素尺度，不能作为硬标签。收益是证据分解更完整，不是识别
置信度更高。

### 3. 模糊携带物：thinking 主要改善概率校准

`no_thinking` 根据手下方的深色多叶轮廓把折叠雨伞置为 0.70，衣物 0.20，软包和未决
各 0.05；描述具体，但明显偏向单一解释。

`thinking=high` 保留深色、手持、向下悬垂、不规则褶皱等可见事实，将折叠雨伞、软包、
成团衣物和未决分别校准为 0.35、0.30、0.20、0.15。它没有凭空获得新像素，却更符合
“在模糊区域进行合理想象”的目标。

## 当前描述能力边界

当前细粒度描述质量可概括为“对象/部件层较强，像素下属性不可依赖”：

- 稳定可用：对象大类、主色、相对位置、携带/连接方式、粗轮廓、明显部件、熟悉图案
  的候选身份；
- 条件可用：由多个弱线索共同支持的桥、镜腿、褶皱、发型等组成关系，必须保留概率和
  替代解释；
- 不可当事实：眼嘴等微小五官、文字、材质细节、单像素结构，以及主要来自 SwinIR
  新增纹理的属性。

## 推荐流程

1. 对候选 ROI 生成内存中的 `A-tight / A-context / B-tight / B-context` 输入板；LR 始终
   是权威测量，SwinIR 仅作非权威提案。
2. 默认执行一次 `no_thinking` Qwen 调用，输出观察、世界知识、互斥假设和未决属性。
3. 归一化概率并采样文本世界；事实 caption 只使用观察，想象 caption 保留知识来源和
   概率，不将最高概率世界转成硬标签。
4. 仅当 ROI 高价值且首轮假设接近、未决质量高或视觉证据与世界知识冲突时，触发一次
   `thinking=high` 复核；复核用于校准和拆分证据，不覆盖首轮记录。
5. 下游分别比较纯视觉、普通 caption、证据文本和概率多世界文本，并始终保留纯视觉
   回退。像素生成链路保持关闭。
