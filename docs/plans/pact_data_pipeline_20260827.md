# PACT 数据管线计划

目标：以当前 SwinIR ×4 原生尺寸输出为唯一图像源，为 SYSU-MM01、RegDB、LLCM 生成可切换的 ReID/Qwen 共用图像，以及 PACT 姿态数据。默认最终尺寸为高512×宽256。

## 不变约定

- `resize`：对数据集已有行人图直接缩放到固定尺寸。
- `person_fit`：YOLO 检测完整行人框，保留带边距的框，等比例放大到目标画布内最大尺寸；空余位置使用同一原图的模糊背景。记录裁剪、缩放、填充及检测质量；不吞异常、不伪造检测结果。
- 两种模式产物目录隔离，尺寸一致，原始身份、模态、摄像头、划分和 RegDB trial 不改变；LLCM 别名保持可追溯。
- StageA 和 Qwen 均读取选定模式的最终图像，不再次超分或暗中改变几何。
- 姿态估计只接收上述最终图像，RGB 与 IR 分别加载对应 YOLO Pose 权重；输出关键点、置信度、四部位软掩码、背景、有效部位标记及42×21 token 网格掩码。缺失/不可见部位显式标记，不编造关键点。
- PACT 尚不实现训练 loss；本任务完成数据和消费接口，训练增强时掩码必须与图像同步。
- 不改主工作树，不改正在运行的超分任务，不启动 ReID 训练；不计算哈希、不下载远程文件。代码使用清晰的数据契约与直接实现，不叠加兜底层。

## 实施顺序

1. 核对超分清单、参考布局实现、三数据集索引和双模态权重。
2. 实现两种图像模式及共同 manifest，保存可审计的坐标变换。
3. 接通 StageA 数据加载和 Qwen 标注入口，提供三数据集切换配置。
4. 实现双模态姿态及 PACT 掩码管线，可独立消费任一图像模式。
5. 单元测试覆盖几何完整性、尺寸、索引、权重路由和掩码；使用三数据集的真实 RGB/IR 图像跑两条完整路径，检查输出与消费接口。
6. 提供执行命令、验证结果和明确的未生成数据范围，不把样本测试说成全量数据完成。

完成条件：代码、配置、接口和真实模型端到端验证全部成立；输出规模与生成状态如实记录。若执行全量生成，必须另外核对完整清单与失败记录，不以进程退出代替覆盖率验证。
