# PACT：姿态锚定的解剖区域反事实 Token 学习

英文暂定名：Pose-grounded Anatomical Counterfactual Token Learning（PACT）

研究基线：3090 服务器上的 Stage-A C3（MBPatch + ViT）

整理日期：2026-08-26
状态：共享图像/姿态预处理与 PACT 解剖掩码插件已实现并通过小样本验证；PACT 训练损失、干预层搜索和正式实验尚未实现或验证。本文不构成训练启动指令。

## 1. 核心想法

不要让姿态估计直接告诉 ViT“应该关注哪里”，而是让姿态估计建立人体区域坐标系，在这个坐标系下测量模型对区域干预的响应，再约束同一身份的 RGB 和 IR 形成相近的区域响应模式。

一句话概括：

> Pose 定义解剖区域；Token 干预测量区域响应；跨模态约束促进同一身份的结构化判别一致性。

这里的“响应”首先是所定义干预下的身份分类分数变化，不直接等同于真实因果贡献，也不解释为可加的身份证据信息百分比。最终研究目标是检验这种训练正则能否改善跨模态检索，而不是预先宣称该机制成立。

## 2. 本版关键更新：干预层不固定为第9层

将干预位置设为可配置参数 `intervention_layer = l`，通过实验选择。

对12层 ViT：

\[
Z^{(l)}=F_{1:l}(x),\qquad f=F_{l+1:12}(Z^{(l)}).
\]

其中 `l=0` 表示在 MBPatch 完成、进入第一个 Transformer block 之前干预；`l=3/6/9` 分别表示完成对应数量的 blocks 后干预。第一轮比较 `l ∈ {0, 3, 6, 9}`，必要时再细化邻近层；第9层仅是候选，不是默认最优。

为什么值得比较：

- 早层：空间位置与局部输入的对应关系更直接，但后续重算更多，扰动也可能影响底层表示形成。
- 中层：可能在局部对应、语义形成与训练成本之间取得折中，是否最佳需要验证。
- 晚层：重算便宜，但区域信息可能已经传播到 CLS 和其他位置，空间掩码不能撤回这些信息。

不能把“CEC loss 最小”的层直接视为最优层。应同时比较验证集检索效果、干预响应是否有效，以及实际训练时间和显存。即便某个晚层提升检索，也只证明它是有效正则位置，不自动证明其区域归因最忠实。

## 3. 与现有 C3 的关系

沿用已核验的 C3 主干、身份采样、分类器及训练配方，不把其他结构变化混入第一轮实验。

- 输入分辨率：512×256。
- 主干：12层、768维 ViT；MBPatch 锚定网格为42×21，共882个 patch tokens，另有 CLS。
- C3 使用 camera-diverse identity sampler、归一化分类器，cosine scale 为30。
- Epoch 0–5 使用 Gray+IR；从 epoch 6 进入 RGB+IR 阶段。
- 原始损失遵循现有代码：ID、Triplet，以及按阶段启用、权重各为0.5的 MSEL 和 DCL；不把它们改成全程等权相加。

已核验的代码提供 `prepare_tokens`、`run_blocks(start_index, end_index, ...)` 和最终特征封装接口，因此可以共享前 `l` 层并重复运行后续 blocks。数据侧仍需新增掩码读取和增强同步，不能只改模型前向。

## 4. 离线姿态与解剖区域

训练前运行固定的姿态估计器，得到关键点坐标及置信度，再构造四个粗粒度区域：

\[
\mathcal A=\{\mathrm{Head},\mathrm{Torso},\mathrm{Arms},\mathrm{Legs}\}.
\]

用关键点高斯、骨段管状区域等方式生成软掩码，并投影到 MBPatch 的锚定 token 网格。软掩码是几何归属权重，不默认是经过校准的概率；需明确区域交叠、人体并集与背景的构造规则。

数据要求：训练图像、身份标签、模态标签、离线关键点/区域掩码、区域置信度与可见性。无需为第一版增加人工身体部位标注。

当前工程统一使用官方 `/home/lab929/ybj/models/qri-v1/checkpoints/yolo11x-pose.pt`。共享 `person_preprocessing` 包在最终 512×256 ViT 输入图像上运行一次姿态估计并保存原始 COCO-17 关键点、边界框、置信度和权重指纹；Qwen 与 PACT 都只读取这份缓存，不再各自加载姿态模型。PACT 插件从缓存派生四部位像素掩码和 token 掩码，因此姿态推理与方法专属资产是单向依赖、可独立验证的两个阶段。

SCHP 与 SAM 仍可供 Qwen 做精细 ROI，但不是 PACT 第一版的依赖，也不会改变共享姿态缓存。权重存在和小样本管线通过不代表 YOLO11x 在全部 IR 图像上已经达到足够精度；正式预处理前仍需抽样统计逐部位可见率与失败率。

掩码必须与图像的缩放、翻转等几何增强同步，并考虑 Random Erasing 后的可见性。对 RGB/IR 只比较双方可靠、可见的部位；整图 pose confidence 不能完全替代逐部位质量判断。

## 5. 正常路径与区域干预

正常路径输出分类 logits `s`，对训练身份 `y` 定义分数：

\[
G(x,y)=s_y-\log\sum_{c\ne y}\exp(s_c).
\]

在候选层 `l` 对区域 `k` 对应的 patch tokens 执行软替换：

\[
\widetilde z_i^{(l,k)}=(1-M_{k,i})z_i^{(l)}+M_{k,i}z_{\mathrm{null}}^{(l)}.
\]

保留原 CLS，复用同一后续主干和分类器，得到干预分数 `G_{\setminus k}^{(l)}(x,y)`。这属于特征替换，不是物理删除 token，也不是重新输入一张真实缺失该部位的图像。

定义区域干预响应：

\[
E_k^{(l)}(x,y)=G(x,y)-G_{\setminus k}^{(l)}(x,y).
\]

正值表示该干预降低分数，负值表示该干预提高分数。各区域存在冗余和协同，响应之和不必等于总分数，不将其称为严格可加的证据分解。

`z_null` 的定义需固定并做对照，例如零值或不依赖当前身份的层级均值；这些选择都不自动保证“中性”或分布内。正常与干预路径还应控制 Dropout/DropPath 的随机差异，以及分类器 BatchNorm 的统计差异，避免把它们误计为区域响应。

## 6. 身份级跨模态响应一致性

保留原构想的最小目标，将四部位响应转为相对分布：

\[
R_k(x)=\frac{\exp(E_k(x)/\tau)}{\sum_j\exp(E_j(x)/\tau)}.
\]

同一身份在各模态内聚合多张图像，而不是要求不同时刻、不同姿态的单张 RGB 与 IR 生硬配对。简化的整图置信度加权形式为：

\[
\bar R_y^m=\frac{\sum_{i:y_i=y,\,m_i=m}q_iR(x_i)}{\sum_{i:y_i=y,\,m_i=m}q_i},\quad m\in\{V,I\}.
\]

\[
L_{\mathrm{CEC}}=\frac1{|\mathcal Y_{\mathrm{valid}}|}\sum_{y\in\mathcal Y_{\mathrm{valid}}}\mathrm{JS}(\bar R_y^V,\bar R_y^I).
\]

实际实现需用逐部位可见性/置信度筛选双方共同可靠区域，并在同一有效区域集合内归一化；没有足够有效区域的身份不参与本次 CEC。

### 公式边界与采样规则

由于 softmax 对整体平移不敏感：

\[
\mathrm{softmax}_k((G-G_{\setminus k})/\tau)=\mathrm{softmax}_k(-G_{\setminus k}/\tau).
\]

因此 CEC 对齐的是区域之间的相对响应，不能区分整体平移后的响应向量，也不能保证各区域具有正贡献。例如 `[1,2,3,4]` 与 `[-9,-8,-7,-6]` 得到相同分布。文中 `R_torso=0.45` 只能解释为归一化相对权重，不能写成“45%的身份信息来自躯干”。

第一版必须保留完整四部位计算，或在共同有效部位集合上明确重新定义目标。不能每次只采一个部位后直接使用现有 softmax+JS：单元素分布恒为 `[1]`，损失及梯度恒为零。采两个部位再归一化也改变了原四维目标。

节省成本优先采用：对少量身份计算完整四部位，或降低 CEC 计算频率；相同层间比较保持相同的身份选择和正则频率。

## 7. 人体与背景的辅助约束

在可比较的干预面积下，分别构造人体和背景干预，定义：

\[
E_{body}=G-G_{\setminus body},\qquad E_{bg}=G-G_{\setminus bg},
\]

\[
L_{struct}=[m-E_{body}+E_{bg}]_+.
\]

其目标是让同等规模的人体区域干预比背景干预更影响分数。若整个人体面积大于可用背景面积，应比较等面积的人体子区域和背景子区域，或跳过不满足条件的样本，不能声称已经实现不存在的“等面积整个人体/背景”对照。

该项作为独立可消融的辅助正则，不宣称能够防止四部位分布坍缩，也不作为区域归因忠实性的充分证明。它约束的是两个干预分数的相对排序，并不直接保证正常检索更好。

## 8. 损失与训练阶段

\[
L=L_{C3}+\alpha(t)\bigl[\lambda_{cec}L_{CEC}+\lambda_{struct}L_{struct}\bigr].
\]

沿用 C3 的阶段切换：前6个 epoch 不启用 PACT；从 epoch 6 开始，在3–4个 epoch 内逐步增加 `alpha(t)`。超参数均为待验证设置，不预设最优权重或温度。

第一轮先比较 C3 与 C3+CEC 的不同干预层。确认 CEC 有效后，再单独评估 `L_struct`，避免同时搜索层位与多个新增约束，无法归因收益。

## 9. 层位实验与计算成本

令后缀 block 数为 `12-l`。完整四部位干预需要1条正常路径和4条干预路径，粗略 block 前向成本为：

\[
C_{4}(l)=l+5(12-l).
\]

若额外计算人体、背景两个独立分支：

\[
C_{6}(l)=l+7(12-l).
\]

| 干预位置 | 四部位 CEC / 原12层前向 | 再加人体与背景 / 原12层前向 |
|---|---:|---:|
| `l=0`，第一个 block 前 | 5.0× | 7.0× |
| `l=3`，第3层后 | 4.0× | 5.5× |
| `l=6`，第6层后 | 3.0× | 4.0× |
| `l=9`，第9层后 | 2.0× | 2.5× |

表中仅是相同长度 tokens、共享前缀时的骨干 block 前向近似，不包含 MBPatch、分类头、反向传播及检查点重算，也不是实际耗时或显存倍数。对身份子批次、低频正则需要另外测量实际开销。

建议分三步开展（均待用户授权启动）：

1. 固定已有 C3 checkpoint，在训练集内划出的诊断/验证样本上检查各层响应、IR 姿态质量、不同 null 选择与重复测量稳定性。固定模型上的检查只能筛选异常设置，不能直接决定训练后的最佳层。
2. 以相同初始化、数据和训练设置比较 `l=0/3/6/9` 的 C3+CEC。先报告相同训练设置下的结果，再单列时间/显存效率；不要把预算变化误归因于层位。
3. 对候选最佳层补充 C3、C3+CEC、C3+struct、C3+CEC+struct 的消融，并加入等面积随机区域和打乱跨模态身份对应的对照。

记录：验证集 Rank-1/mAP/mINP、每步时间、峰值显存、有效样本比例、区域响应的符号/幅度和分布。保持 C3 原有数据划分与评测约定；层位和权重在验证集选择，不反复使用最终测试结果调参。SYSU 正式结果按10次 gallery trial 的聚合值报告，并区分 gallery trials 与训练随机种子。

机制验证应独立于训练约束：比较早层或输入侧的区域干预、随机区域对照，以及干预前后同人/异人的检索相似度或排序变化。输入侧遮挡也可能引入伪影，须设置对照，不能把它当作无误差的因果真值。

## 10. 推理阶段

只保留原始 C3：`Image → MBPatch → ViT → Feature → Retrieval`。

只要 PACT 完全是训练期分支，测试阶段不需要 Pose、区域掩码或干预路径，模型结构与理论推理 FLOPs 可保持不变。实际延迟仍以同环境测量为准。

## 11. 创新定位与已有工作

潜在贡献是：以姿态定义固定的解剖干预单位，对同一身份的 RGB/IR 区域干预响应施加一致性训练，并研究干预层位对跨模态泛化及归因可靠性的影响。

不能把“Pose+反事实”或“同身份跨模态一致性”单独作为首次提出的概念：

- [CAA，2023](https://www.sciencedirect.com/science/article/abs/pii/S0167865523000739)：通过反事实预测效应监督注意力学习，并对齐 RGB/IR 注意力图。PACT 拟对齐的对象是姿态区域特征替换后的响应分布，而非注意力图；不能说 CAA 完全不关心预测效果。
- [Pose-guided counterfactual inference for occluded person re-identification，2022](https://www.sciencedirect.com/science/article/pii/S0262885622002165)：已有姿态与反事实推断结合的 ReID 方法，任务与具体干预机制不同。
- [CM²GT，2025](https://www.sciencedirect.com/science/article/pii/S0031320325001700)：摘要明确提出跨粒度、跨模态的身份级显著性一致性，因此 PACT 的差异应落在具体干预及响应目标上。
- [CFSR-Net，2025](https://www.sciencedirect.com/science/article/pii/S0031320324008823)：使用跨模态一致性学习局部特征的重要性评分，是局部重要性方向的相关对照。
- [Counterfactual-Guided Implicit Correspondence Prompting，2026](https://www.ieee-jas.net/en/article/doi/10.1109/JAS.2025.125432)：已核验发表信息，但本轮未取得可完整核对的方法全文，作为后续查重线索，不据标题认定重复或排除重合。

当前判断：工程可行性较高，方法具有增量创新潜力；尚未通过完整文献排查和实验证明首创性、有效性或因果解释。层位搜索本身主要是方法设计与消融，只有形成可复现的机制发现，才可能成为进一步贡献。

## 12. 当前共识

认可“不固定第9层、通过实验寻找适合的干预层”。第一版优先验证四部位的身份级相对干预响应一致性，不叠加更多损失，也不把分类分数变化过度解释为真实身份证据比例。

最关键的实证问题是：姿态定义的区域干预一致性，相比随机区域或普通一致性正则，是否带来稳定、可解释的跨模态检索收益？
